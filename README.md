# АПК — Образовательный портал

Сайт для **Агинского педагогического колледжа им. Базара Ринчино**.

Стек: React (Vite) + Express + SQLite + JWT. Данные хранятся на сервере, не в браузере.

## Локальный запуск

```bash
# 1. Фронт
npm install
npm run server:install

# 2. API (порт 3000) — в отдельном терминале
npm run start
# или с автоперезагрузкой: npm run dev:server

# 3. Vite (порт 5173) — проксирует /api и /uploads на бэкенд
npm run dev
```

Откройте http://localhost:5173

## Root-аккаунт

При первом запуске API создаётся администратор из `server/.env`:

| Параметр | Значение по умолчанию |
|----------|------------------------|
| Логин | `root` |
| Пароль | `ChangeMe_Root_2026!` |

Смените `ROOT_PASSWORD` и `JWT_SECRET` перед выкладкой на сервер. После первого создания смена `ROOT_PASSWORD` в `.env` не обновляет уже существующий аккаунт в БД.

## Прод на VPS

1. `npm ci && npm run server:install && npm run build`
2. Настройте `server/.env` (`JWT_SECRET`, `ROOT_*`, `CLIENT_ORIGIN=https://apk.c0ns7.ru`)
3. Запустите `npm start` (или systemd/pm2) — Express отдаёт API и статику из `dist`
4. Nginx → reverse proxy на порт 3000

Подробности: [DEPLOY.md](./DEPLOY.md)

## Возможности

- Вход по логину/паролю (учётные записи создаёт администратор)
- Студент: задания, сдача, оценки, чат, объявления, расписание
- Преподаватель: предметы, задания, проверка, чат, Excel
- Администратор: пользователи, аналитика, экспорт
