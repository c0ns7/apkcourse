# АПК — Образовательный портал (прототип)

Прототип сайта для **Агинского педагогического колледжа им. Базара Ринчино**.

Верстка и логика на фронтенде, данные хранятся в `localStorage` браузера (без бэкенда).

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Возможности

- **Регистрация и вход** (студент / преподаватель)
- **Студент:** задания, сдача работ, просмотр оценок
- **Преподаватель:** предметы, закрепление студентов, создание заданий, проверка и оценки
- **Администратор:** список пользователей, статистика

## Сброс демо-данных

В DevTools → Application → Local Storage удалите ключи `apk-portal-data` и `apk-portal-session`.
