# АПК — Образовательный портал (прототип)

Прототип сайта для **Агинского педагогического колледжа им. Базара Ринчино**.

Верстка и логика на фронтенде, данные хранятся в `localStorage` браузера (без бэкенда).

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Демо-аккаунты

| Роль | Логин | Пароль |
|------|-------|--------|
| Студент | student | student123 |
| Преподаватель | teacher | teacher123 |
| Администратор | admin | admin123 |

## Возможности

- **Регистрация и вход** (логин/пароль, согласие на ПДн, учебный год)
- **Студент:** задания разных типов, сдача работ с вложениями, оценки/зачёты, чат, объявления
- **Преподаватель:** предметы, типы заданий в кабинете, проверка (2–5 или зачёт/незачёт), чат, Excel
- **Администратор:** пользователи, аналитика по годам/студентам, экспорт отчётов

## Сброс демо-данных

В интерфейсе администратора — «Сбросить демо», либо в DevTools → Application → Local Storage удалите `apk-portal-data-v4` и `apk-portal-session`.
